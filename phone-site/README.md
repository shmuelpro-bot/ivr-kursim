# קו חכם – אתר תדמית למערכות טלפוניות

אתר סטטי (HTML/CSS/JS בלבד) – לא צריך שרת, מסד נתונים או PHP. עובד על כל אחסון, כולל אחסון חינמי בהוסטינגר.

## העלאה להוסטינגר (2 דקות)
1. היכנסו ל-hPanel ← **Websites** ← **File Manager** של הדומיין.
2. פתחו את התיקייה `public_html` ומחקו ממנה את `default.php` (אם קיים).
3. העלו את הקובץ `phone-site.zip` ← קליק ימני ← **Extract** לתוך `public_html`.
   - ודאו ש-`index.html` נמצא **ישירות** בתוך `public_html` (לא בתת-תיקייה).
4. גלשו לדומיין – האתר באוויר.

## התאמה אישית
בראש הקובץ `script.js`:
```js
const CONFIG = {
  whatsapp: "972500000000",   // מספר הוואטסאפ שלכם (972 + המספר בלי 0)
  email: "info@example.com",  // המייל שלכם
};
```
טופס יצירת הקשר שולח את הפנייה ישירות לוואטסאפ או למייל שלכם – בלי שרת.

## קבצים
- `index.html` – כל תוכן הדף
- `style.css` – העיצוב
- `script.js` – אנימציות, סימולטור IVR, סינון רעיונות וטופס
- `assets/favicon.svg` – אייקון
- `.htaccess` – דחיסה ומטמון
